# 格式与验证范围

GDF/SYM 采用严格原生记录解析，不用扫描可见字符串来猜完整几何。已支持的
GDF v6 记录包括符号定义、实例、旋转/镜像、拉伸、世界引脚坐标、线、圆、弧、
文字和参数。记录偏移属于当前文件版本，每次修改后重新读取。
未知操作码、截断、异常长度、越界坐标、不安全共享定义和身份冲突会被拒绝。

SCF v4 的信号记录、事件编码和支持的结构字段可读写。未知前缀、尾部和未编辑
记录保留原字节；不安全引用变化拒绝。输入支持 0、1、X、Z，不能将未知值作为
零。输出/internal 轨迹的真实含义由原厂 Simulator 确认。

GDF source connectivity 保留源实例和引脚。显式数字范围可展开逐位连接，WIRE
按声明范围的位置映射成员；参数化宽度、部分层次和内部连接仍可能 partial。
综合 EDIF 需要原厂编译并可能合并门或更名。连接保持检查不能代替行为验证。

内置字体及显式 Windows 字体字段可编辑。GDF 没有文本编码标记；调用者需
选择 latin1 或 windows-936。中文字体与 width/height 需要真实度量。
原生蓝色引脚标签来自 pin 的可见属性；同一位置的重复黑色 DOC 会遮盖它。
重复清理要求文字、位置和格式等条件一致，并保留原生 pin 及其身份。

公开测试包含严格语法、事务写入、备份恢复、分页、接口、身份、输入去重、
取消、缓存、SCF 事件及元数据等验证。数值变换观察和自制 XOR 波形提供独立
预期；安装了原厂软件后额外运行库语法、编译、仿真及网表测试。
没有硬件的测试不声称已经完成烧录验证。
